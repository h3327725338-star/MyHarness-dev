# Tool description
- Save long-term memories on your own, without asking first: preferences, habits, rules, corrections and lasting facts the user states about themselves, plus anything they ask to remember, import, correct or update; say in one short line what you saved. Save an observed habit only after it has shown up several times, marked as observed; never save secrets, one-off details or guesses written as facts. Update a matching memory instead of adding a duplicate, and fix one right away when the user says it is wrong. Write the resident user profile entry only when the user imports a profile or asks to change it. Omit id to create; pass a known id to update it. Deleting is done with memory_delete, never here.
